# Anti-AI Slop Rules

## Strict Prohibitions
1. **No Purple / Pink Gradients**: Strictly ban `#8b5cf6` to `#ec4899` or generic "cyberpunk" gradients.
2. **No Generic Sparkle Clichés**: Do not stick sparkle icons or "AI Magic" tags on ordinary data.
3. **No Decorative Emojis**: Never use emojis in primary CTA buttons, table headers, or system alerts. Use clean SVG icons (Lucide).
4. **No Artificial Em Dashes**: Avoid writing robotic text padded with constant em dashes (`—`).
5. **No Infinite Decorative Pulsing**: Micro-interactions must respond to human actions (hover, focus, click), not run endless pulsing animations.
6. **No Fake Glassmorphism**: Avoid blurry frosted glass overlays (`backdrop-blur-md bg-white/10`) that ruin readability. Use solid, crisp background cards.
7. **WCAG AA Contrast**: Text must always have at least 4.5:1 contrast against its background.
