# Taste & High-End Design System

## Visual Rules
1. **Calm Emerald & Forest Palette**:
   - Primary Background: Deep Calm Forest `#022c22`
   - Light Cards / Contrast Surfaces: Soft Mint / Sand `#ecfdf5` / `#f0fdf4` / `#f8fafc`
   - Primary Accent: Crisp Emerald `#059669` / `#10b981`
   - Text: High-contrast rich charcoal / zinc (`#09090b` on light, `#f8fafc` on dark)
2. **Typography**:
   - Modern clean sans (Plus Jakarta Sans / Geist / Inter cleanly weighted).
   - Clear editorial hierarchies: 2xl-4xl for confident headings, 14-16px for body, 12px uppercase tracking-wider for meta tags.
3. **8-Point Spacing Grid**:
   - Consistent rhythm: 8px, 16px, 24px, 32px, 48px, 64px.
4. **Solid, Crisp Elements**:
   - Sharp, tactile buttons with distinct active and hover states.
   - Distinct borders (`border-emerald-900/40` or `border-stone-200`) instead of oversized blurred shadows.
5. **Human-Centric Copy**:
   - Authentic, friendly, unpretentious tone (BM santai tak cringe, EN crisp and clear).
